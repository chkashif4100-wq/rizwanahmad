AHMED RAZA - STUDENT WEBSITE

Files:
- index.html  : website structure and content
- style.css   : colours, layout, responsive design
- script.js   : mobile navigation and current year
- profile.jpg : add your own profile picture using this exact filename

HOW TO USE:
1. Extract the ZIP file.
2. Copy your profile picture into this same folder.
3. Rename your picture to profile.jpg (JPG/JPEG format is recommended).
4. Double-click index.html to open the website in your browser.

To edit the website, open the files in Visual Studio Code or any text editor.
The site is built with plain HTML, CSS and JavaScript. Google Fonts requires an internet connection.
